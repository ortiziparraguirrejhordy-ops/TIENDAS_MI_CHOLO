# TIENDAS MI CHOLO

## Sistema de Gestión de Ventas

Proyecto del curso Fundamentos de Programación
Universidad Privada del Norte - UPN.

## Objetivo

Digitalizar el registro manual de ventas mediante
un sistema informático funcional, modular y seguro.

## Funcionalidades previstas

- CRUD de productos.
- Registro de ventas.
- Control de inventario.
- Búsqueda y ordenamiento.
- Base de datos SQLite.
- Interfaz gráfica.
- Modo consola.
- Exportación de archivos CSV.
- Copias de seguridad.
- Validación de datos.

## Tecnologías

- Python
- SQLite
- Tkinter
- Git
- GitHub
